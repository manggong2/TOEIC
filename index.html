TOEIC 단어 시험지 생성기

Day1~Day30 챕터별 엑셀 단어를 업로드하면, 랜덤으로 뽑아 시험지 PDF를 만들어줘요.

1 엑셀 파일 업로드

기대하는 형식: 시트(탭) 하나 = 챕터(Day) 하나, 시트 이름이 곧 챕터 이름(예: Day1)이 됩니다. 각 시트의 A열 = 영단어, B열 = 뜻으로 인식합니다. 파일 여러 개를 한 번에 올려도 되고, 한 파일에 여러 시트가 있어도 됩니다.
index.html과 같은 폴더에 words.xlsx 파일을 커밋해두면, 페이지가 열릴 때 자동으로 불러옵니다. (파일을 그냥 컴퓨터에서 더블클릭해 로컬로 열 때는 브라우저 보안 정책상 자동 로드가 안 될 수 있어요 — 그럴 땐 아래에서 직접 업로드하면 돼요.)

4 미리보기 & PDF 저장

"PDF로 저장"은 화면에 보이는 레이아웃(2단 정렬 포함)을 그대로 이미지로 캡처해서 실제 PDF 파일로 바로 다운로드해요. 모바일 사파리에서도 2단 레이아웃이 그대로 유지됩니다. 혹시 실물 프린터로 바로 인쇄하고 싶으면 "브라우저 인쇄로 저장"을 쓰세요 (이 경우 기기별로 2단 정렬이 깨질 수 있어요).
